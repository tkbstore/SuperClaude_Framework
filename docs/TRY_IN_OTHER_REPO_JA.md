# 別リポジトリで SuperClaude を試すときの手順

SuperClaude は**一度インストールすると、仮想環境ではなくユーザー環境（~/.claude/commands/sc/ と CLI）に置かれるため、他のリポジトリでもそのまま利用できます。** 別リポで再度インストールする必要はありません。

このドキュメントは、**別のリポジトリを開いた状態で SuperClaude を試すとき**に、作業内容を把握しやすくし、負荷を抑えるための運用方針をまとめたものです。**利用時は、このドキュメントを Agent に渡して従わせてください。**

---

## 1. 前提

- すでに [CLONE_SETUP_JA.md](CLONE_SETUP_JA.md) に従って SuperClaude をインストール済みであること。
- これから試すのは「SuperClaude を入れたマシンで、別のリポジトリを開き、そのリポ内で `/sc:orchestrate` 等を使う」運用であること。

---

## 2. 別リポジトリで試すときの運用

### 2.1 作業内容の可視化

- **何をやっているか把握できるように、ウィンドウを見せる**運用とする。
- 作業内容が分かる状態で画面を共有するか、ディスプレイ上で作業ウィンドウを明示してから進める。

### 2.2 ディスプレイの分割と Claude Code の起動

- **ディスプレイを 8 分割**し、必要に応じて**各分割で Claude Code を起動**する。
- 複数セッションを並べて比較・確認しやすくし、オーケストレーションや並列作業の様子を把握しやすくする。

### 2.3 モデルの選択

- **モデル最適化のため、小さめのモデルを指定して使用する**ことを推奨する。
- コスト・応答速度・負荷のバランスを取りたい場合は、必要に応じて Claude Code のモデル設定で小型モデルを選択する。

---

## 3. Agent に渡すとき

**別リポジトリで SuperClaude を試す際は、このドキュメント（TRY_IN_OTHER_REPO_JA.md）を Agent に渡し、「この手順に従って動作すること」を指示してください。** これにより、可視化・8 分割・小さめモデルといった運用が一貫して適用されます。

- セットアップ手順が必要な場合は、あわせて [CLONE_SETUP_JA.md](CLONE_SETUP_JA.md) も渡すとよいです。
